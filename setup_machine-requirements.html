Machine Requirements

Overview

The team has several windows laptops to use during the season and at competitions. Because of the special software used, we cannot use the school's Windows laptops from the TechEd department. However, we do not have laptops for everyone, hence a personal laptop is recommended.

Operating system

FRC primarily supports Windows (required for our drive station laptop at competitions). New in 2027, all tools will work on Mac & Linux for programming during the season. Chromebooks may work for training, but not for programming the competition robot.

Specs

Programming is generally resource intensive. Intel i5/AMD Ryzen5, 16MB RAM, 512GB SSD is a recommended base. Gaming latops are always a great choice.
